**AI OS** is a state-of-the-art, open-source multi-agent artificial intelligence operating system. Built with Next.js Turbopack, glassmorphism design system, and OpenRouter + Pollinations AI pipelines, it features **50+ specialized autonomous agents**, real-time streaming, voice controls, and an interactive code sandbox.

---

## ✨ Features & Capabilities

- 🤖 **50+ Autonomous AI Agents**: Specialized agents for Code Generation, Debugging, Data Analysis, SEO, Writing, Legal, Finance, AI/ML, and more.
- 🎨 **Real-Time Image & Video Generation**: Powered by Pollinations AI for instant high-resolution art and motion clips.
- 🎙️ **Speech-to-Text Voice Input**: Dictate prompts directly to any agent using Web Speech API with real-time transcription.
- 🔊 **Text-to-Speech (TTS) Read Aloud**: Listen to AI responses in clear natural voice audio playback.
- ⚡ **Interactive Code Sandbox Preview**: Instant live iframe sandbox execution for HTML, CSS, JavaScript, React components, and SVG graphics.
- 🧠 **Dynamic Intent Routing**: Automatic request detection that routes user prompts to the single best agent for maximum accuracy.
- 🔐 **Firebase Authentication & Mock Mode**: Secure sign-in support alongside seamless guest demo mode.
- 👑 **Creator Identity System**: Built-in identity awareness — proudly created by **Shiwam**.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Shiwam59/Multi-Agent-AI-Platform-.git
cd Multi-Agent-AI-Platform-/ai-os
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the `ai-os` directory:
```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to Vercel

1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com/new) and import your `Multi-Agent-AI-Platform-` repository.
3. Set root directory to `ai-os`.
4. Add your `OPENROUTER_API_KEY` in Environment Variables.
5. Click **Deploy**! 🚀
